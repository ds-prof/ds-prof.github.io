# ДС ПРОФ — профессиональное снабжение предприятий

Одностраничный сайт компании: каталог продукции, корзина-заявка, контакты.

- Страница: `index.html`
- Картинки: `img/` (WebP)
- Заявки с формы уходят в Google Apps Script (адрес `GAS_URL` в `index.html`).

Чтобы обновить сайт, замените `index.html` и отправьте изменения в ветку `main` — GitHub Pages опубликует его автоматически.
